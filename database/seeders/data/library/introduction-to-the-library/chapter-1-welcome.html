Welcome to the Library

This is a small, built-in sample book so the Library page always has something to show — on a fresh install, in CI, or on any machine that hasn't imported a real EPUB collection yet.

The Library stores books as a simple hierarchy:

  • A Book belongs to an Author and has a title, description, and cover.
  • A Book has many Chapters, shown in reading order.
  • Each Chapter's content renders in the reader, with theme, font-size, and page-turning controls available from the settings drawer (the gear icon in the top-right corner of the reader).

Real books are added either through the admin upload form (/admin/library, drag-and-drop a .epub file) or in bulk with:

php artisan library:seed-directory /path/to/your/epub/folder
