How to Use This Library

A few things worth knowing as a reader:

Reading modes

Open any chapter and click the gear icon to open reading settings. From there you can switch between:

  • Scroll — the default, a normal continuously-scrolling page.
  • H-Page — horizontal page-flip, like a paperback.
  • V-Page — vertical page-flip.
  • Autoscroll — the page scrolls itself at a speed you choose.

Themes and font size

The same settings drawer has four reading themes (White, Sepia, Dark Sepia, Black) and font-size controls, both remembered across chapters and future visits.

Finding books

  • /library lists every book that's finished processing.
  • Each author's name links to a page listing everything by that author.
  • If you're an admin, /admin/library shows upload status, lets you edit a book's title/author/description, and retry anything that failed to import.

That's the whole reading experience — enjoy the library.
